# 💰 Project 2: Expense Tracker

A web app that tracks your expenses. Built with Python and Flask.

---

## 🎯 What It Does

1. Enter an expense (like 25.50)
2. The program adds it to your total
3. Shows statistics and history

---

## ✨ Features (What My App Actually Has)

| Feature | How it works |
|---------|--------------|
| ➕ Add expenses | Type amount, click button |
| 💰 Running total | Shows big green number |
| 📊 Number of expenses | Counts how many you added |
| 📈 Average expense | Total ÷ number of expenses |
| 🔥 Highest expense | Shows your biggest expense |
| 📋 Expense history | Lists every expense with number |
| 🔄 Reset button | Clears everything |
| ✅ Success messages | "Added $505.00" in green |
| ❌ Error handling | Prevents crashes |
| 📱 Mobile friendly | Works on phone |
