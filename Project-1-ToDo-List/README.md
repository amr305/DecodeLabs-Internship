# 📝 Project 1: To-Do List

A simple command-line task manager built with Python. Demonstrates the use of **lists** to store multiple items in a single variable.

## 🎯 Goal

Build a program where users can add tasks and view them using a Python list.

## 🔑 Key Concepts

| Concept | Code |
|---------|------|
| Creating an empty list | `self.tasks = []` |
| Adding to a list | `self.tasks.append(task)` |
| Looping through a list | `for i, task in enumerate(self.tasks, 1):` |
| Class and methods | `class TodoList:` and `def add_task(self):` |
